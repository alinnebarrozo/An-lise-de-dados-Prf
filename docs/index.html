Carregando 194 mil ocorrências e 477 mil pessoas envolvidas…
Fonte: PRF, dados abertos de acidentes (datatran, acidentes, todas_causas_tipos), jan/2024 a ago/2026. Tratamento: notebook Analise_PRF_ETL_SQL (pandas + SQL/DuckDB, modelo estrela). Versão web do painel construído em Python, Streamlit e Plotly.
